CrayonAllPortals

Route planner for Minecraft All Portals speedruns. Works solo or in co-op, and only one player needs to run it.

  • Windows
  • Minecraft speedrun
  • Solo & co-op

What it does

An All Portals run means lighting every End portal in the game. Enter one stronghold per ring and CrayonAllPortals predicts the rest of the ring, shows the ideal blind distance for each ring in the overworld and the nether, and works out the best route through all of them.

In co-op, players pair up on paths. The solver balances the paths so they all finish around the same time, and you can give faster players more work by raising their weight.

How to use it

  1. Download CrayonAllPortals.exe and run it. There's nothing to install.
  2. Enter the X and Z of one stronghold in each ring, or paste an F3+C command, then press Set. CrayonNavAssist helps you measure these.
  3. Set the number of players and how long the solver should search. More time gives better routes.
  4. Click Generate Paths. The map draws the best routes found so far while it works.
  5. Edit any path's stronghold list to change it. The map updates as you type.
  6. Click Copy for NavAssist and paste each player's path into their CrayonNavAssist.

What gets copied

The copied text lists each path as [id, x, z] lines, ready for CrayonNavAssist:

Everything you enter is saved automatically and comes back the next time you open the app.
